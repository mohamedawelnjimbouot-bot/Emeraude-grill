# Emraude Grill — site vitrine

Site vitrine responsive en HTML, CSS et JavaScript, conçu pour Emraude Grill à Foumban.

## Fichiers
- `index.html` : contenu du site
- `style.css` : couleurs, mise en page et adaptation mobile
- `script.js` : menu mobile et année automatique
- `images/` : dossier prévu pour vos futures photos locales

## Avant de publier
1. Confirmez l'adresse exacte et les horaires du restaurant.
2. Remplacez les exemples de plats et la mention « Tarifs à confirmer » par le vrai menu.
3. Remplacez les photos provisoires par vos propres photos. Les images actuelles sont chargées depuis Unsplash et nécessitent une connexion Internet.
4. Vérifiez le numéro de téléphone et le lien WhatsApp dans `index.html`.
5. Ouvrez `index.html` dans un navigateur pour tester le site.

## Publication gratuite avec GitHub Pages
1. Créez un compte sur https://github.com/ si vous n'en avez pas.
2. Créez un nouveau dépôt public, par exemple `emraude-grill`.
3. Téléversez `index.html`, `style.css`, `script.js` et le dossier `images/` à la racine du dépôt.
4. Dans le dépôt, ouvrez **Settings → Pages**.
5. Dans **Build and deployment**, choisissez **Deploy from a branch**, puis `main` et `/ (root)`, et enregistrez.
6. Attendez quelques minutes. GitHub affichera l'adresse publique de votre site dans la section Pages.

Le lien sera généralement de la forme `https://VOTRE-NOM.github.io/emraude-grill/`. Remplacez `VOTRE-NOM` par votre nom d'utilisateur GitHub. Ce lien est un exemple de format, pas une adresse déjà publiée.

## Modifier le site
- Texte et téléphone : ouvrez `index.html` dans un éditeur de texte.
- Couleurs et présentation : modifiez les variables au début de `style.css`.
- Photos : placez vos photos dans `images/` et remplacez les URLs `images.unsplash.com` dans `style.css` par des chemins tels que `images/grillades.jpg`.
- Pour le numéro WhatsApp, utilisez le format international sans `+` ni espaces dans l'URL `https://wa.me/237697182424`.

## Remarques
- L'hébergement statique GitHub Pages convient à ce site vitrine et ne nécessite pas de serveur de paiement.
- Les offres et conditions des plateformes peuvent évoluer ; consultez leur documentation actuelle.
- Aucun formulaire de réservation, paiement en ligne ou système de commande n'est installé dans cette première version.
